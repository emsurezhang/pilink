# PiLink 运维手册

## 拓扑与端口（北京 ECS，仅 IP，无域名）

| 位置 | 组件 | 监听 | 说明 |
|---|---|---|---|
| Mac | Gateway | `127.0.0.1:7788` | 业务（HTTP/WS/PWA 静态资源） |
| Mac | Bridge 通道 | `127.0.0.1:7789` | 仅回环，Bridge 扩展外连 |
| Mac | frpc | 出站 ECS:7000 | launchd 常驻，自动重连 |
| ECS | frps | `:7000` | 控制连接，TLS + token；安全组放行 |
| ECS | Nginx | `:8443` | 唯一公网业务入口，IP 证书终结 TLS/WSS |
| ECS | ACME 验证 | `:80` 或 `:443` | 仅签发/续期时临时开放（NET-6） |

访问地址：`https://<ECS 公网 IP>:8443`。安全组：常开 `8443` + `7000`；`80` 按需临时。
**不要开放 frps 代理端口（17788）与 dashboard**（frps `proxyBindAddr=127.0.0.1` 保证）。

## IP 证书（NET-5 / R9）

- Let's Encrypt short-lived IP 证书（约 6 天有效），HTTP-01（临时开 80）或 TLS-ALPN-01（临时开 443）
- 续期：每日检查；剩余 <48h 每小时重试；成功后 `nginx -s reload`
- 续期失败告警：ECS 上的检查脚本在失败时通知（Mac 在线时经 Gateway 推送/本机通知）
- 失败备选：私有 CA（手机安装并完全信任根证书）或 Tailscale 私网组网（见设计文档 §11.1.1）

## Mac 常驻（NET-3）

```bash
pilink install-launchd    # com.pilink.gateway（KeepAlive + RunAtLoad）
# frpc 同理：deploy/launchd/com.pilink.frpc.plist，cp deploy/frp/frpc.toml ~/.pilink/
```

## 保持唤醒（电源）

- 设置页开关 → `caffeinate -i -w <pid>`；合盖运行需外接电源/外显等条件（macOS 限制）
- `pilink doctor` 检查睡眠设置

## 常用排查

```bash
pilink doctor              # Pi 版本、端口、frpc、证书、睡眠
tail -f ~/.pilink/gateway.log
sqlite3 ~/.pilink/pilink.db 'SELECT * FROM audit_log ORDER BY id DESC LIMIT 50;'   # 审计
```

## 交接话术（SYNC-3）

1. 终端：`/quit`（或保持 TUI 开着由 Bridge 弹窗确认接管）
2. 手机：打开同一会话 → Gateway 获取租约 → Host 模式托管
3. 回到电脑：手机「结束托管」，终端 `pi --session <path>`（手机端可一键复制该命令）
